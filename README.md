w05_oop
📘 ภาพรวม (Overview)

โปรเจกต์ w05_oop เป็นตัวอย่างโค้ดสำหรับแสดงแนวคิดเชิงวัตถุ (Object-Oriented Programming – OOP) ในหลายภาษา
โดยแต่ละโฟลเดอร์ประกอบด้วยตัวอย่างโปรแกรมที่ใช้ศึกษาความเหมือนและความต่างของการเขียน OOP ในแต่ละภาษา

📁 โครงสร้างโปรเจกต์ (Project Structure)
w05_oop/
├── cpp/       # ตัวอย่าง OOP ด้วยภาษา C++
├── cs/        # ตัวอย่าง OOP ด้วยภาษา C#
├── java/      # ตัวอย่าง OOP ด้วยภาษา Java
└── python/    # ตัวอย่าง OOP ด้วยภาษา Python

🚀 วิธีการใช้งาน (How to Use)
1️⃣ Clone โปรเจกต์
git clone https://github.com/AthiwatJantasri/w05_oop.git

2️⃣ เข้าไปในโฟลเดอร์โปรเจกต์
cd w05_oop

3️⃣ เปิดโฟลเดอร์ภาษาที่ต้องการศึกษา

เช่น cpp/, java/, python/ หรือ cs/

4️⃣ สำรวจไฟล์ซอร์สโค้ด

ไฟล์ในแต่ละภาษาจะเป็นนามสกุลตามภาษา เช่น

.cpp

.cs

.java

.py

🎯 วัตถุประสงค์ของโปรเจกต์

เพื่อช่วยให้นักศึกษาเข้าใจแนวคิดพื้นฐานของ OOP

เพื่อใช้เปรียบเทียบการทำงานของ OOP ในแต่ละภาษา

เพื่อเป็นแหล่งอ้างอิงสำหรับการเรียนการสอนด้าน OOP
